산도리 홈페이지 — 로고 드로잉 인트로 수정본

사용 방법
1. ZIP을 압축 해제합니다.
2. index.html과 assets 폴더를 같은 위치에 둡니다.
3. 기존 홈페이지의 index.html을 수정본으로 교체합니다.
   사진 파일과 기존 본문은 변경하지 않았습니다.

인트로
- 네모 3개는 동일한 선 속도로 큰 도형 → 중간 도형 → 작은 도형 순서로 시작해 동시에 완성됩니다.
- 영어 Sando.li → 일본어 サンドリ → 한글 산도리 순서로 글씨가 드러납니다.
- 마지막 한글 로고와 딸기 산도 사진을 보여준 후 메인 화면으로 전환합니다.
- 방문 세션당 한 번 재생합니다. 주소 끝에 ?intro=1을 붙이면 다시 재생합니다.
- SKIP 또는 Esc로 건너뛸 수 있습니다.
- 기기의 동작 줄이기 설정을 켜면 정지된 한글 로고를 잠시 보여줍니다.

원본 확인 사항
제공된 logo_en.png와 logo_jp.png는 동일한 일본어 이미지입니다.
따라서 영어 Sando.li만 기기에 설치된 손글씨 계열 폰트로 표시하며,
영어 로고 원본이 생기면 해당 글씨 모양으로 교체할 수 있습니다.
네모와 일본어·한글은 제공된 이미지 원본을 마스킹해 사용합니다.

매장 사진 및 철학 업데이트
- 인트로 후 매장 전경 → 실내 → 메뉴판 → 식물이 있는 실내 순으로 5초마다 전환합니다.
- 사진 아래 산도리의 철학을 배치했습니다.
- 이전/다음, 사진 선택, 일시정지, 모바일 스와이프를 지원합니다.
- 이번 버전은 새 사진 4장이 추가되어 index.html과 assets 폴더를 함께 교체해야 합니다.

하단 주소 및 링크 업데이트
- 대구 중구 국채보상로 553
- Instagram, 네이버 지도, Google Maps 링크 추가(새 탭으로 열림)
- 직전 매장 사진 버전을 사용 중이면 index.html만 교체하면 됩니다.

로고 선 속도 업데이트
- 실제 SVG 경로 길이에 비례해 각 도형의 그리기 시간을 정했습니다.
- 가장 큰 도형은 0.1초에 시작하고 세 도형 모두 1.35초에 완성됩니다.
- 기존 영어 → 일본어 → 한글 순서와 사진, 주소, 링크는 유지했습니다.

검색 등록 및 로고 시작점 업데이트
- 네이버 소유확인 태그를 index.html에 추가했습니다.
- 구글 인증은 HTML 태그가 아니라 제공된 HTML 파일 방식입니다. 파일 이름과 내용은 원본 그대로입니다.
- index.html, googledd5e912fd4ebbd3f.html, sitemap.xml, robots.txt를 GitHub Pages 게시 루트(현재 index.html과 같은 위치)에 업로드하세요.
- 기존 CNAME 파일은 유지하세요.
- 배포 후 https://sandoli.kr/googledd5e912fd4ebbd3f.html 에 인증 문구가 나오는지 확인하고 구글과 네이버에서 소유확인을 완료하세요.
- 두 서비스에 https://sandoli.kr/sitemap.xml 을 제출하고 홈페이지의 색인/수집을 요청하세요.
- 실제 소유확인 및 검색 등록 완료는 각 서비스에서 확인해야 합니다.
- 각 네모의 시작·끝점을 왼쪽 아래로 변경했습니다. 동일 속도와 동시 완성 시간은 유지됩니다.
